# Download Catalog

Chrome으로 받은 파일의 **출처·시각·목적**을 자동으로 기록하고, 같은 파일을 다시 받으면 **중복/새 버전**을 알려 주는 윈도우 트레이 프로그램입니다. 이름이 겹치는 파일만 이름 뒤에 시각을 붙여 구분하고, 그 밖의 파일은 옮기거나 이름을 바꾸지 않습니다.

> **개발자**: 일등감자 (deepstack.owen@gmail.com) · **대상**: Windows 10/11 · Chrome · Python 3.12

## 실행

```powershell
# 최초 1회
py -3.12 -m venv .venv      # 또는 설치된 python.exe 전체 경로 사용
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File packaging\make_shortcut.ps1   # "Download Catalog.lnk" 바로가기 만들기

# 실행 (콘솔 창 없이): "Download Catalog.lnk" 더블클릭, 또는
.\.venv\Scripts\pythonw.exe run.pyw
```

`.pyw` 파일은 윈도우에 연결된 프로그램이 없으면 더블클릭이 동작하지 않을 수 있어서 바로가기를 만들어 쓰는 것을 권합니다(바로가기에는 내 PC의 경로가 들어가므로 저장소에는 포함하지 않았습니다). 시작 시 오류는 `%APPDATA%\DownloadCatalog\error.log`에 기록됩니다.

Python 없이 쓰려면 설치 프로그램을 직접 만들 수 있습니다([설치 프로그램 만들기·배포](#설치-프로그램-만들기배포) 참고). 설치 파일(exe)은 저장소에 포함하지 않았습니다.

이미 실행 중일 때 한 번 더 실행하면, 실행 중인 프로그램의 **카탈로그 창이 앞으로** 열립니다.

## 사용법

### 파일을 받으면
- 설정에 따라 **바로 팝업** / **조용히 알림**(작은 알림을 누르면 입력창) / **사용 안 함** 중 하나로 동작합니다.
- 입력창은 **같은 사이트에서 지난번에 쓴 목적·메모**(없으면 마지막으로 쓴 목적)를 미리 채워 줍니다. `Enter` 저장, `Esc` 건너뛰기.
- 연달아 받으면 **"나머지 N개도 같은 목적으로"** 로 한꺼번에 입력하고, **"이 사이트는 다시 묻지 않기"** 를 체크하면 그 사이트는 기록만 합니다.
- 새 파일 / **새 버전**(파란 배경) / **이미 받은 파일**(노란 배경)을 구분해 알려 줍니다. 긴 주소는 도메인만 보이고 **자세히**를 누르면 전체가 펼쳐집니다.
- 같은 이름의 파일을 받을 때: Chrome의 "다른 이름으로 저장" 창에 뜨는 `이름 (1).zip`을 `이름_년-월-일-시분.zip`(예: `이름_2026-10-11-1530.zip`)으로 자동 변경합니다(저장 버튼은 직접 누름). 저장 창이 **열려 있는 폴더**(하위 폴더 포함)에 원래 이름의 파일이 있을 때 바꿉니다. 창 없이 바로 저장되는 설정이면 저장이 끝난 뒤 같은 형식으로 이름을 바꿉니다.

### 하위 폴더
감지 폴더 **안의 하위 폴더(여러 단계 아래 포함)도 함께 감지**합니다(환경설정 > 일반에서 켜고 끌 수 있고 기본은 켜짐).
- 폴더째 옮겨 오거나, 감지 폴더 밑의 새 폴더에 파일을 받아도 기록됩니다. 이름이 겹쳐 시각을 붙일 때는 그 파일이 있는 폴더 안에서 처리합니다.
- `.`으로 시작하는 폴더(`.git` 등)는 건너뜁니다.
- 압축을 풀면 풀린 파일마다 기록·입력 요청이 생기므로, 번거로우면 끄거나 "조용히 알림"/제외 규칙을 쓰세요.
- 켜기 전(또는 꺼 둔 동안)에 하위 폴더에 생긴 파일은 나중에 거슬러 가져오지 않습니다.

### 프로그램이 꺼져 있던 동안 받은 파일
프로그램을 켤 때마다 감지 폴더를 한 번 훑어서 **기록에 없는 파일을 자동으로 추가**합니다(이름은 바꾸지 않고, 입력창도 띄우지 않고 "N개 파일을 새로 기록했어요" 알림만 보여 줍니다). 처음 실행할 때는 폴더에 이미 있는 최근 30일 파일도 기록에 넣을지 물어봅니다.

### 카탈로그 창 (트레이 아이콘 더블클릭)
- 열 제목을 눌러 **정렬**(▲▼), 도메인·크기·**상태**(파일이 아직 있는지) 열. 긴 내용은 마우스를 올리면 전체가 보입니다.
- 검색 + **필터**: 기간(오늘/7일/30일), 목적, 미입력만, 새 버전만, 중복 제외. 아래에 "총 N건 중 M건 표시".
- **우클릭 메뉴**: 파일 열기, 폴더 열기, 주소 복사, 목적/메모 수정, 기록 삭제. 키보드: `Delete` 삭제, `Enter` 파일 열기, `Ctrl+F` 검색, `Ctrl+A` 전체 선택, `Esc` 검색어 지우기.
- 여러 건을 골라 **목적을 한꺼번에** 바꾸거나 삭제할 수 있습니다(파일은 삭제되지 않음).
- 창 크기·위치·열 너비·정렬을 기억합니다.
- **"목적을 입력하지 않은 기록 N건"** 알림에서 **하나씩 입력**을 누르면 키보드만으로(`Enter` 저장 후 다음) 빠르게 정리할 수 있습니다.

### 트레이 아이콘
일시정지하면 회색 아이콘으로 바뀌고, 마우스를 올리면 "오늘 N건 기록 / 목적 안 쓴 것 M건"이 보입니다. 우클릭 메뉴: 카탈로그 열기 / 목적 안 쓴 기록 정리 / 최근 받은 파일 5개 / 환경설정 / 일시정지 / 종료.

### 환경설정 (트레이 우클릭 또는 카탈로그 창의 버튼)
| 탭 | 설정 |
|---|---|
| 일반 | 감지 폴더(저장하면 재시작 없이 바로 적용), 하위 폴더도 함께 감지, Windows 시작 시 자동 실행, 목록 글자 크기 |
| 팝업 | 바로 팝업 / 조용히 알림 / 사용 안 함, 입력 없으면 N초 후 자동 건너뛰기, 목적 목록 편집 |
| 제외 규칙 | 작은 파일(MB), 확장자, 사이트는 기록만 하고 입력창은 생략 |
| 정보 | 버전·개발자(일등감자, 메일 주소를 누르면 새 메일 쓰기)·기록 개수, 데이터 폴더/오류 기록 열기, 기록 백업 만들기 |

설정은 `%APPDATA%\DownloadCatalog\settings.json`, 기록은 같은 폴더의 `catalog.db`(SQLite)에 저장됩니다. 프로그램을 새 버전으로 올릴 때 기록 파일 구조가 바뀌면 **자동으로 `catalog.db.bak-v*` 백업을 만든 뒤** 옮깁니다.

## 개발
```powershell
.\.venv\Scripts\python.exe -m pytest tests -v        # 자동 테스트(화면 테스트 포함, 실제 창이 잠깐 뜸)
.\.venv\Scripts\python.exe -m download_catalog --downloads-dir <폴더> --data-dir <폴더> --no-lock --no-first-run-dialog   # (cwd=src)
```
시험용 환경변수 `DOWNLOADCATALOG_INSTANCE_SUFFIX`를 지정하면 중복 실행 방지 이름이 달라져, 이미 실행 중인 프로그램과 부딪히지 않고 시험할 수 있습니다.

## 한계
- 출처는 윈도우가 파일에 붙이는 `Zone.Identifier`, 없으면 Chrome 기록(기본 프로필)에서 찾으며, 둘 다 없으면 "알 수 없음"입니다.
- 환경설정으로 감지 폴더를 바꿔도 이전 폴더의 파일을 따로 가져오지는 않습니다.
- 주소 속 로그인 토큰(`at=...` 등)은 기록에 그대로 저장됩니다(화면에서는 도메인만 보이고 "자세히"를 눌러야 펼쳐짐).

## 설치 프로그램 만들기·배포
```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```
결과물 `dist\DownloadCatalog-Setup-1.2.4.exe` 하나만 다른 Windows PC로 복사해 실행하면 됩니다(Python 설치 불필요, 관리자 권한 불필요 — 현재 사용자 폴더에 설치). 이미 설치된 PC에서는 같은 설치 파일을 덮어서 실행하면 업데이트됩니다.
설치 중 **실행 방식**을 선택합니다(설치 후에는 환경설정 > 일반에서 바꿀 수 있습니다).
- *Windows를 시작할 때 자동으로 실행* (기본): `HKCU\...\Run`에 등록
- *자동 실행하지 않음*: 시작 메뉴에서 직접 실행

제거는 "설정 → 앱"에서 하며, 자동 실행 등록도 함께 삭제됩니다. 기록(`%APPDATA%\DownloadCatalog`)은 제거해도 남습니다.
빌드에는 `.venv`(pyinstaller 포함)와 Inno Setup 6(`winget install JRSoftware.InnoSetup`)이 필요합니다.
