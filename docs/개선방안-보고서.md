**보고서 9장의 결정 사항**은 답을 받기 전이라 아래 기본값으로 진행했습니다: 토큰은 저장(화면에서 가림) / 처음 실행 때 기존 파일 가져오기를 **물어봄** / 팝업은 기본 "바로 팝업"(설정에서 변경).

## 1. 이 보고서는 무엇인가요?

Download Catalog는 Chrome으로 받은 파일을 **자동으로 기록**해 주는 프로그램입니다.
"언제, 어디서 받았는지"를 기록하고, 같은 파일을 또 받으면 **"이미 받은 파일이에요"**, **"새 버전이에요"** 라고 알려 줍니다.
받을 때 **"왜 받았는지(목적)"** 도 한 줄 적어 둘 수 있습니다.

지금도 이 기본 기능은 잘 동작합니다. 하지만 실제로 오래 쓰면 이런 불편이 생길 수 있습니다.

- 😟 컴퓨터를 꺼 둔 동안 받은 파일은 **기록에서 빠진다**
- 😟 팝업에 목적을 적는 게 귀찮아서 **계속 '건너뛰기'만 누르게 된다**
- 😟 기록은 쌓였는데 **원하는 파일을 찾기 불편하다**

이 보고서는 이런 불편을 찾아내고, **어떻게 고치면 좋은지** 정리한 문서입니다.

## 2. 먼저 결론: 가장 먼저 고치면 좋은 5가지

| 순위 | 무엇을 | 한 줄 설명 | 난이도 |
|---|---|---|---|
| 1 | **놓친 파일 따라잡기** | 프로그램을 켤 때, 꺼져 있는 동안 받은 파일을 찾아서 기록한다 | 쉬움 |
| 2 | **목적 입력을 덜 귀찮게** | 지난번에 쓴 목적을 기억해서 미리 채워 준다 | 보통 |
| 3 | **목록 화면을 쓰기 편하게** | 열 제목을 눌러 정렬하고, 오른쪽 클릭 메뉴를 만든다 | 보통 |
| 4 | **주소 속 비밀번호 가리기** | 주소에 섞여 있는 인증 코드가 화면에 그대로 보이지 않게 한다 | 쉬움 |
| 5 | **환경설정 늘리기** | 지금은 폴더만 바꿀 수 있는데, 자동 실행 설정 등을 추가한다 | 보통 |

> **난이도** : 쉬움 = 하루 안쪽으로 가능 / 보통 = 며칠 / 어려움 = 일주일 이상 또는 별도 준비 필요 (대략적인 감입니다)

## 3. 지금 프로그램은 어디까지 되나요?

### 잘 되는 것 ✅
- 다운로드가 끝나면 자동으로 알아채서 기록한다 (파일 이름, 받은 시각, 받은 주소)
- 같은 파일인지, 새 버전인지 알려 준다
- 이름이 겹치면 `이름_2026-10-11-1530.zip` 처럼 시각을 붙여서 구분한다
- 팝업 글자가 크고, 메모 칸에 바로 입력할 수 있다
- 목록 화면에서 검색하고, 여러 개를 한꺼번에 삭제할 수 있다
- 작업표시줄 오른쪽 아래(트레이)에 아이콘이 보이고, 감시할 폴더를 바꿀 수 있다
- 설치 파일로 다른 컴퓨터에도 설치할 수 있다

### 코드를 살펴보고 찾은 아쉬운 점 ⚠️

| 아쉬운 점 | 쉽게 말하면 |
|---|---|
| 시작할 때 폴더를 훑지 않음 | 프로그램은 "지금부터 새로 생기는 파일"만 지켜봅니다. 꺼져 있던 동안 받은 파일은 모릅니다 |
| 열 정렬이 없음 | 목록의 "받은 시각", "파일명"을 눌러도 순서가 바뀌지 않습니다 |
| 화면 선명도 설정이 없음 | 화면 배율을 크게 쓰는 컴퓨터에서 글자가 살짝 흐리게 보일 수 있습니다 |
| Chrome 기본 프로필만 참고 | Chrome에서 계정을 여러 개 쓰면 일부 파일의 출처를 못 찾을 수 있습니다 |
| 저장 형식에 버전 번호가 없음 | 나중에 기록 항목을 늘리고 싶을 때, 이미 쓰고 있는 사람의 기록을 안전하게 옮길 방법이 없습니다 |
| 두 번 실행하면 아무 반응 없음 | 이미 켜져 있을 때 한 번 더 누르면 조용히 꺼져서, 사용자는 "안 켜지네?" 하고 느낍니다 |
| 설정이 폴더 하나뿐 | 나머지 동작은 설정으로 바꿀 수 없습니다 |
| 목적 기본값이 "업무"로 고정 | 개인 파일을 많이 받는 사람은 매번 직접 바꿔야 합니다 |

## 4. 기능 개선 제안

각 항목은 **지금 상황 → 불편한 점 → 이렇게 바꾸자** 순서로 적었습니다.

### F1. 놓친 파일 따라잡기 ⭐ 가장 먼저

- **지금 상황**: 프로그램은 폴더에 *새로 생기는* 파일만 알아챕니다.
- **불편한 점**: 컴퓨터를 켜기 전, 프로그램을 끈 동안, 감시 폴더를 바꾸기 전에 받은 파일은 **기록에서 빠집니다.** 나중에 알아도 되돌릴 방법이 없습니다.
- **이렇게 바꾸자**: 프로그램을 켤 때마다 폴더를 한 번 훑어서 **기록에 없는 파일을 찾아 추가**합니다.
  - 마지막으로 껐던 시각 이후에 생긴 파일만 보면 빠르게 끝납니다.
  - 처음 설치할 때는 "이미 있는 파일도 기록할까요?" 하고 물어봅니다.
  - 한꺼번에 많이 찾았을 때 팝업이 수십 개 뜨지 않도록, **"12개 파일을 새로 기록했어요"** 알림 한 번만 보여 줍니다.
- **난이도**: 쉬움

### F2. 목적 입력을 덜 귀찮게 ⭐

- **지금 상황**: 파일을 받을 때마다 팝업이 뜨고, 목적을 고르거나 적어야 합니다.
- **불편한 점**: 귀찮으면 사람은 **무조건 '건너뛰기'** 를 누르게 됩니다. 그러면 "왜 받았는지 기억하기"라는 이 프로그램의 핵심이 사라집니다.
- **이렇게 바꾸자**:

| 방법 | 예시 |
|---|---|
| 지난번 값 기억 | 지난번에 "학습"을 골랐으면, 이번엔 "학습"이 미리 선택돼 있다 |
| 사이트별 기억 | `github.com`에서 받을 때마다 "개발"을 자동으로 제안한다 |
| 목적 목록 편집 | "업무, 학습, 개인…" 대신 내가 쓰는 말로 목록을 바꾼다 |
| 묻지 않을 파일 정하기 | 1MB보다 작은 파일, `.png` 같은 확장자, 특정 사이트는 **기록만 하고 팝업은 안 띄운다** |
| "이 사이트는 다시 묻지 않기" | 팝업 안에 체크 칸을 둔다 |
| 한 번에 입력 | 연달아 3개를 받으면 "나머지 2개도 같은 목적으로" 버튼을 누른다 |

- **난이도**: 보통

### F3. 버전 이력 보기

- **지금 상황**: 프로그램 안에는 "이 파일은 저 파일의 새 버전이다"라는 연결 정보가 저장돼 있습니다.
- **불편한 점**: 하지만 화면에는 `버전 2` 같은 숫자만 보이고, **어떤 파일들이 한 가족인지** 볼 수 없습니다.
- **이렇게 바꾸자**: 파일을 선택하면 같은 계열 파일을 **받은 순서대로 한 줄씩** 보여 줍니다. (예: `setup.exe` → `setup_2026-09-01.exe` → `setup_2026-10-11.exe`)
- **난이도**: 보통

### F4. 파일이 아직 있는지 표시

- **지금 상황**: 받은 파일을 다른 폴더로 옮기거나 지워도 기록은 그대로 남습니다.
- **불편한 점**: 목록에서 더블클릭해야 "파일을 찾을 수 없음"이라는 걸 알게 됩니다.
- **이렇게 바꾸자**: 목록에 **상태 열**을 추가해 "있음 / 없음"을 보여 주고, 없는 파일은 회색으로 표시합니다. 필요하면 "다시 찾기" 기능으로 같은 내용의 파일을 다른 폴더에서 찾아 연결합니다.
- **난이도**: 보통

### F5. 다른 브라우저·계정 지원

- **지금 상황**: Chrome의 기본 계정(Default 프로필) 기록만 참고합니다.
- **불편한 점**: 계정을 여러 개 쓰거나 Edge, 웨일을 쓰면 **받은 주소를 못 찾아서** "알 수 없음"으로 남을 수 있습니다.
- **이렇게 바꾸자**: 컴퓨터에 설치된 모든 Chrome 계정, Edge, 웨일의 기록을 자동으로 찾아봅니다.
- **난이도**: 보통

### F6. 내보내기와 백업

- **이렇게 바꾸자**: 목록을 **엑셀에서 열 수 있는 파일(CSV)** 로 저장하고, 기록 전체를 **백업·복원**하는 메뉴를 만듭니다.
- **왜 필요한가요?**: 컴퓨터를 바꾸거나 윈도우를 다시 설치해도 기록을 가져갈 수 있습니다.
- **난이도**: 쉬움

### F7. 감시 폴더 여러 개

- **지금 상황**: 폴더 한 개만 감시합니다.
- **이렇게 바꾸자**: 환경설정에서 **폴더 목록**을 관리합니다. (예: 다운로드 + 바탕화면 + 작업용 폴더)
- **난이도**: 보통

### F8. 더 자세한 출처 정보 (먼 훗날)

- **지금 상황**: 출처는 긴 인터넷 주소뿐입니다.
- **아이디어**: 어떤 **웹페이지 제목**에서 받았는지 같은 정보는 브라우저 안에서만 알 수 있습니다. Chrome에 **확장 프로그램**을 따로 만들어 설치하면 가능하지만, 만드는 일이 큽니다.
- **난이도**: 어려움 (뒤로 미룸)

## 5. 화면(UI) 개선 제안

### U1. 목록 화면을 쓰기 편하게 ⭐

사용자가 가장 자주 보는 화면인데, 기본 기능이 아직 부족합니다.

| 기능 | 내용 |
|---|---|
| **열 정렬** | "받은 시각", "파일명" 같은 제목을 누르면 순서가 바뀐다 |
| **도메인 열** | `https://drive.usercontent.google.com/download?id=...` 대신 **`drive.usercontent.google.com`만** 보여 준다. 마우스를 올리면 전체 주소가 나온다 |
| **크기·상태 열** | 파일 크기와, 파일이 아직 있는지 보여 준다 |
| **오른쪽 클릭 메뉴** | 파일 열기, 폴더 열기, 주소 복사, 메모 수정, 버전 이력, 삭제를 한 곳에서 |
| **키보드 단축키** | `Delete` 삭제, `Enter` 파일 열기, `Ctrl+F` 검색칸으로 이동 |
| **여러 개 한꺼번에 수정** | 여러 파일을 골라서 **목적을 한 번에** 바꾼다 (지금은 삭제만 가능) |
| **창 모양 기억** | 다음에 열 때도 지난번 크기·위치·열 너비 그대로 |
| **글자 크게** | 팝업처럼 목록 글자도 크게 볼 수 있게 한다 |

### U2. 검색을 더 똑똑하게

- **지금 상황**: 글자를 입력해서 찾는 검색 한 칸뿐입니다.
- **이렇게 바꾸자**: 검색칸 옆에 **빠른 버튼**을 둡니다.
  - `오늘 / 7일 / 30일` · `목적 고르기` · `목적 안 쓴 것만` · `새 버전만`
  - "총 120건 중 8건" 처럼 결과 개수도 보여 줍니다.
- **난이도**: 보통

### U3. 건너뛴 기록 정리하기

- **불편한 점**: 건너뛴 기록이 쌓여도 어디 있는지 모릅니다.
- **이렇게 바꾸자**: 트레이 메뉴와 목록 위쪽에 **"목적 안 쓴 기록 12건"** 이라고 알려 줍니다. 누르면 그 기록만 모아서, **키보드만으로 빠르게** 하나씩 입력하는 화면이 열립니다.

### U4. 팝업 개선

| 항목 | 지금 | 개선 |
|---|---|---|
| **작업 방해** | 팝업이 뜨면서 입력 위치를 가져와서, 다른 창에서 타자 치던 글자가 팝업으로 들어갈 수 있다 | "**조용히 알림**" 선택지: 화면 구석에 작은 알림만 띄우고, 눌렀을 때만 입력창이 열린다 |
| **자동 닫힘** | 계속 떠 있는다 | 30초 동안 아무것도 안 하면 자동으로 건너뛰기(선택) |
| **키보드** | 마우스로 눌러야 한다 | `Enter` = 저장, `Esc` = 건너뛰기 |
| **긴 주소** | 주소가 여러 줄을 차지한다 | **도메인만** 보여 주고, "자세히"를 누르면 전체를 펼친다 |
| **경고 구분** | "이미 받은 파일" 안내가 평범한 글자색 | 눈에 띄는 배경색으로 구분 |

### U5. 환경설정 창 늘리기

지금은 "감지 폴더" 하나뿐입니다. 아래처럼 **탭**으로 나눠서 정리합니다.

| 탭 | 들어갈 설정 |
|---|---|
| **일반** | 감시 폴더(여러 개), **Windows 켜질 때 자동 실행 켜기/끄기**, 글자 크기 |
| **팝업** | 팝업 / 조용히 알림 / 사용 안 함, 목적 목록 편집 |
| **제외 규칙** | 이 크기보다 작은 파일, 이 확장자, 이 사이트는 팝업 안 띄우기 |
| **정보** | 프로그램 버전, 기록 개수, 기록 폴더 열기, 백업·복원 |

### U6. 트레이 아이콘 개선

- 일시정지하면 **아이콘 모양이 바뀌게** 한다 (지금은 메뉴를 열어 봐야 알 수 있음)
- 마우스를 올리면 **"오늘 5건 기록 / 목적 안 쓴 것 3건"** 을 보여 준다
- 메뉴에 **최근 받은 파일 5개**를 넣어서, 누르면 바로 폴더가 열리게 한다

### U7. 프로그램을 또 실행했을 때

- **지금 상황**: 이미 켜져 있는데 또 누르면 아무 반응 없이 사라집니다.
- **이렇게 바꾸자**: 이미 켜진 프로그램의 **목록 화면을 앞으로 띄워** 줍니다. 그러면 사용자는 "아, 켜져 있구나" 하고 바로 알 수 있습니다.

### U8. 화면이 선명하게 보이도록

- 화면 배율을 높게 쓰는 모니터에서도 글자가 또렷하도록 **"고해상도 대응"** 을 프로그램에 알려 줍니다. 한 줄 정도의 간단한 작업입니다. (난이도: 쉬움)
- 윈도우 **다크 모드**에 어울리는 색상은 나중에 검토합니다.

## 6. 안정성·보안 개선 제안

### R1. 주소 속 비밀번호 가리기 ⭐

- **실제로 있었던 일**: 구글 드라이브에서 받은 파일의 주소가 이렇게 기록됩니다.
  `https://drive.usercontent.google.com/download?id=...&at=AMrWOn1r...`
  맨 끝의 `at=...` 은 **로그인했다는 증명 코드(토큰)** 입니다. 이런 코드가 기록과 화면에 그대로 남습니다.
- **왜 위험한가요?**: 화면을 다른 사람에게 보여 주거나, 목록을 내보내서 공유할 때 **코드가 같이 새어 나갈 수 있습니다.**
- **이렇게 바꾸자**:
  - 화면에는 **`?` 앞까지만** 보여 주고 뒤쪽은 가립니다. ("자세히"를 눌러야 전체 표시)
  - 설정에 **"주소 뒤쪽 코드는 아예 저장하지 않기"** 옵션을 둡니다.
  - 내보내기를 할 때는 뒤쪽 코드를 빼고 저장합니다.
- **난이도**: 쉬움

### R2. 나중을 위한 기록 저장 구조 준비

- **지금 상황**: 기록이 저장되는 파일(데이터베이스)에 "몇 번째 버전의 구조인지" 표시가 없습니다.
- **왜 문제인가요?**: 나중에 새 기능 때문에 항목을 하나 더 저장하게 되면, 이미 프로그램을 쓰던 사람의 **기존 기록을 안전하게 새 구조로 옮길** 방법이 없습니다.
- **이렇게 바꾸자**: 구조 버전 번호를 저장해 두고, 프로그램이 시작할 때 **필요하면 자동으로 옮기기 전에 백업부터** 만듭니다.
- **난이도**: 쉬움~보통. 새 기능(F2, F4 등)을 넣기 **전에** 해 두는 것이 안전합니다.

### R3. 아주 큰 파일 처리

- **지금 상황**: 파일마다 "지문(해시)"을 계산해서 같은 파일인지 비교합니다. 수 GB짜리 파일은 이 계산에 시간이 걸립니다.
- **불편한 점**: 계산하는 동안 뒤에 받은 파일의 처리가 늦어질 수 있습니다.
- **이렇게 바꾸자**: 이름·시각·주소는 **먼저 바로 기록**하고, 지문 계산은 **뒤에서 천천히** 합니다. 계산 중이라는 표시도 목록에 보여 줍니다.
- **난이도**: 보통

### R4. 오류 기록 관리

- **지금 상황**: 문제가 생기면 `error.log` 파일에 적히지만, **크기 제한이 없고** 사용자에게 알려 주지도 않습니다.
- **이렇게 바꾸자**: 1MB가 넘으면 새 파일로 바꾸고, 같은 오류가 반복되면 **"문제가 있어요 → 기록 보기"** 알림을 띄웁니다.
- **난이도**: 쉬움

### R5. 테스트 보강

- **지금 상황**: 자동 테스트 25개가 핵심 기능을 확인합니다. 하지만 팝업·목록·환경설정 화면과 설치·제거는 개발 중 임시로 확인했을 뿐, 정식 테스트로 남아 있지 않습니다.
- **이렇게 바꾸자**: 그 확인 작업을 **정식 테스트로 저장**해 두고, 설치 파일을 만들 때마다 **자동으로 "설치 → 실행 → 제거"까지 점검**하게 합니다.
- **왜 필요한가요?**: 기능을 고칠 때 다른 곳이 망가지는 일(회귀)을 바로 알아챌 수 있습니다.

## 9. 결정이 필요한 4가지

개선을 시작하기 전에 정해 주시면 좋은 것들입니다.

1. **주소 속 코드(토큰)를 어떻게 할까요?**
   ① 아예 저장하지 않는다 ② 저장은 하되 화면에서만 가린다
2. **처음 설치할 때, 폴더에 이미 있는 파일도 기록에 넣을까요?**
   (넣는다면 최근 한 달 정도만 할지, 전부 할지)
3. **팝업은 지금처럼 바로 띄울까요, "조용한 알림"을 기본으로 할까요?**
4. **1차 개선을 한꺼번에 진행할까요, 항목별로 나눠서 진행할까요?**

### 추천
**1차부터 진행**하기를 권합니다. 작업량이 적은 항목이 대부분이고, 순서가 자연스럽습니다.
**"기록이 빠지지 않게 한다 → 저장 구조를 안전하게 한다 → 찾아보기 편하게 한다"** 의 순서로 해 두면, 그 위에 2차·3차 기능을 쌓기가 쉬워집니다.

## 10. 용어 풀이

| 용어 | 쉬운 설명 |
|---|---|
| **트레이** | 작업표시줄 오른쪽 아래, 시계 옆에 작은 아이콘들이 모여 있는 곳 |
| **팝업** | 갑자기 화면에 나타나는 작은 창 |
| **기록(DB, 데이터베이스)** | 정보를 표 형태로 정리해서 저장해 두는 파일. 이 프로그램에서는 `catalog.db` |
| **해시(지문)** | 파일 내용으로 계산한 긴 글자열. 내용이 **한 글자라도 다르면 완전히 다른 값**이 나와서, "같은 파일인지" 확인하는 데 쓴다. 파일 이름은 같아도 내용이 다르면 지문도 다르다 |
| **토큰** | "이 사람은 로그인했어요"를 증명하는 임시 인증 코드. 비밀번호처럼 조심해서 다뤄야 한다 |
| **프로필(Chrome)** | Chrome에서 계정별로 나뉜 작업 공간. 계정이 여럿이면 프로필도 여럿 |
| **CSV** | 표 데이터를 단순한 글자 파일로 저장한 형식. 엑셀에서 바로 열 수 있다 |
| **DPI(고해상도 대응)** | 화면 배율이 높을 때 글자와 그림이 흐려지지 않게 하는 설정 |
| **마이그레이션** | 저장 구조가 바뀔 때, 기존 데이터를 새 구조로 안전하게 옮기는 작업 |
| **확장 프로그램** | 브라우저에 추가로 설치하는 작은 기능 프로그램 |
| **SmartScreen** | 윈도우가 "처음 보는 프로그램"을 실행할 때 띄우는 경고 화면 |
| **디지털 서명** | "이 프로그램은 누가 만들었고 변조되지 않았다"를 증명하는 도장 같은 것 |
| **회귀(리그레션)** | 기능을 고쳤더니 멀쩡하던 다른 기능이 망가지는 문제 |
