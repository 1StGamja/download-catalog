## 2. 시험 방법과 환경

- **격리**: 모든 시험은 임시 폴더와 임시 데이터 폴더에서 실행했습니다. 이 PC에서 사용자님이 쓰고 계신 프로그램·기록(`%APPDATA%\DownloadCatalog`)·Chrome 프로필은 건드리지 않았습니다. (중복 실행 방지 이름도 시험용으로 분리)
- **진짜 환경으로 한 것**: 실제 Chrome, 실제 윈도우 저장 창, 실제 트레이 아이콘, 실제 설치 프로그램(조용한 모드), 실제 레지스트리, 실제 Tk 창.
- **재현**: 아래 [8장](#8-다시-시험하는-방법)의 명령으로 모두 다시 돌릴 수 있습니다.

| 출처 조사 | 윈도우가 붙인 `Zone.Identifier`에서 주소·참조 페이지 읽기 | pytest(실제 파일에 기록), 진짜 Chrome | ✅ |

| 파일 지문·중복·새 버전 | SHA-256이 표준 계산과 일치, 같은 내용=중복, 같은 이름 다른 내용=v2·v3로 이전 기록과 연결 | pytest, 대용량 시험, 진짜 Chrome | ✅ |

| 놓친 파일 따라잡기(F1) | 꺼져 있던 동안 생긴 파일만 기록, 이미 기록된 파일·`.crdownload`·폴더 제외, 이름은 바꾸지 않음, 다시 돌려도 중복 없음, 없는 폴더도 오류 없음 | pytest, 전체 흐름(개발·exe) | ✅ |
| 처음 실행 질문 | 기록이 없는 처음 실행에서만 "최근 30일 파일도 넣을까요?" 질문(시험에서는 질문 끄는 옵션 사용) | 전체 흐름(옵션), 코드 점검 | ⚠️ 질문 창 자체는 직접 눌러 보지 못함 |
| 제외 규칙(F2) | 작은 파일·확장자(대소문자 무관)·사이트(하위 도메인 포함, 비슷한 이름은 제외 안 됨)는 기록만 하고 입력 대상에서 빠짐 | pytest, 전체 흐름 | ✅ |

## 7. 시험 때문에 이 PC에 생긴 흔적

- 시험용 임시 폴더(`%TEMP%\dc_*`)는 남아 있어도 무방하며, 사용자님의 기록·설정에는 영향이 없습니다.
- 트레이 "항상 표시" 시험에서 **`python.exe`(개발용 파이썬)의 트레이 아이콘 항목**이 "항상 표시"로 설정되었습니다. 이 프로그램과 무관한 개발 환경의 항목이며, 설정 → 개인 설정 → 작업 표시줄 → 기타 시스템 트레이 아이콘에서 바꿀 수 있습니다.
- 시험용 자동 실행 값(`DownloadCatalogUnitTest`)과 시험 설치는 모두 제거했습니다.
